# 方法论

## 人物筛选标准

### 筛选原则

1. **知名度**：在唐代文学、政治、艺术等领域有显著影响
2. **数据充足性**：CBDB 中有足够关系数据支撑网络构建（至少 3 条关系记录）
3. **代表性**：覆盖不同领域、时期、地域

### 筛选流程

1. 从 CBDB 提取所有唐代（618–907）人物
2. 按关系记录数量排序
3. 结合历史知名度人工筛选
4. 最终名单约 100 人（根据数据质量调整）

## 关系判定规则

### 关系类型分类

| 类型 | 说明 | 数据来源 |
|------|------|----------|
| 亲属 | 血缘、婚姻关系 | KIN_DATA |
| 师友 | 师生、朋友关系 | ASSOC_DATA |
| 同僚 | 官场同事关系 | ENTRY_DATA, STATUS_DATA |
| 政治 | 政治联盟、对立关系 | ASSOC_DATA |
| 文学 | 诗文唱和、文学交流 | ASSOC_DATA |

### 关系确认标准

1. **直接证据**：CBDB 中有明确记录的关系
2. **间接推断**：基于共同经历、地理位置等推断的关系
3. **置信度分级**：
   - 1.0：直接证据，明确记录
   - 0.8：强间接证据
   - 0.6：中等间接证据
   - 0.4：弱间接证据

### 不确定关系处理

1. 不确定关系单独标记，不混入确定关系
2. 在可视化中用虚线或不同颜色表示
3. 在数据文件中用 confidence 字段标记

## 数据质量控制

### 质量检查项

1. **完整性**：关键字段（姓名、生卒年、关系）不能为空
2. **一致性**：生卒年逻辑一致（birth < death）
3. **唯一性**：人物基于 cbdb_id 去重
4. **准确性**：关系类型在预定义范围内

### 质量检查脚本

```bash
python scripts/quality_check.py
```

输出：
- 缺失值统计
- 异常值检测
- 关系类型分布
- 人物覆盖度

## 可视化原则

### 静态网络图

1. **节点**：人物，大小表示关系数量
2. **边**：关系，粗细表示关系强度，颜色表示关系类型
3. **布局**：力导向布局，减少交叉
4. **标注**：关键人物标注姓名

### 交互式网络图

1. **节点交互**：悬停显示详情，点击查看关系
2. **边交互**：悬停显示关系详情
3. **筛选**：按关系类型、时期、地域筛选
4. **搜索**：按姓名搜索人物

## 数据更新流程

1. 从 CBDB 获取最新数据
2. 运行提取脚本 `extract_cbdb.py`
3. 运行质量检查 `quality_check.py`
4. 更新可视化
5. 记录变更日志
